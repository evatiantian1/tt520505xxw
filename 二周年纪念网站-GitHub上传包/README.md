# 小五 × 湉湉｜二周年纪念

这是一个纯静态网站，可以直接通过 GitHub Pages 发布。

## 上传

1. 打开这个文件夹。
2. 把 `index.html`、`styles.css`、`script.js`、`assets` 和 `.nojekyll` 一起拖到 GitHub 仓库的根目录。
3. 提交后进入仓库的 `Settings` -> `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，然后保存。

发布完成后，GitHub 会在 Pages 页面显示网站地址。
